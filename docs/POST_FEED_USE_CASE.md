Module – Feed Screen (Home Tab)
1. Introduction
   The Feed Screen (Home Tab) is a central module of the application that displays a collection of content posts
   in reverse-chronological order. It acts as the primary landing area after user login and provides access
   to post browsing, reading, and content management features. This module includes read and write capabilities depending on user permissions.

2. Purpose
   Provide a dynamic feed of posts with pagination and real-time updates.
   Allow users to read and explore published content safely and efficiently.
   Enable authorized users to create, edit, and delete posts.

3. Actors & Permissions
   | Actor             | Description        | Permissions                                                                 |
   | ----------------- | ------------------ | --------------------------------------------------------------------------- |
   | **Standard User** | Authenticated user | View feed, view post details                                                |
   | **Admin User**    | Administrator role | View, create, edit, delete												   |

4. Features Overview
   Infinite scroll and pull-to-refresh feed experience.
   Post detail view with rich content (text, images, blocks).
   Create, edit, delete posts (role-based).
   Post import via JSON (admin only).

5. Use Cases
   UC-1 View Feed
   | Item               | Description                                                                                                                               |
   | ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
   | **Precondition**   | User is authenticated, feed feature is enabled                                                                                            |
   | **Main Flow**      | 1. User opens Home Tab<br>2. App loads initial page of posts<br>3. Scrolling loads more pages automatically<br>4. Pull-to-refresh reloads |
   | **Alternate Flow** | No posts → Show empty state                                                                                                               |
   | **Error Handling** | Network error → Show retry + cached posts if available                                                                                    |

UC-2 View Post Details
| Item               | Description                                                                                                   |
| ------------------ | ------------------------------------------------------------------------------------------------------------- |
| **Precondition**   | At least one post exists                                                                                      |
| **Main Flow**      | 1. User selects a post<br>2. App navigates to Post Details<br>3. Render full post (rich text + image support) |
| **Error Handling** | Post not found → Show "not found" page<br>Broken image → show placeholder                                     |

UC-3 Create Post (Admin only)
| Item               | Description                                                                                                |
| ------------------ | ---------------------------------------------------------------------------------------------------------- |
| **Precondition**   | User has admin role                                                                                        |
| **Main Flow**      | 1. Click “+ Create Post”<br>2. Fill form (title, content, images, tags)<br>3. Submit -> validation -> save |
| **Validation**     | - Title required<br>- Slug autogenerated and unique<br>- Content min. 1 block                              |
| **Error Handling** | Duplicate slug or network error → Show retry                                                               |

UC-4 Edit Post (Admin only)
| Item               | Description                                                      |
| ------------------ | ---------------------------------------------------------------- |
| **Precondition**   | Admin or original post author                                    |
| **Main Flow**      | 1. Click “Edit” on a post<br>2. Update fields<br>3. Save changes |
| **Error Handling** | Permission denied / Save error                                   |

UC-5 Delete Post (Admin only)
| Item               | Description                                                |
| ------------------ | ---------------------------------------------------------- |
| **Precondition**   | Admin or post author                                       |
| **Main Flow**      | 1. Click Delete<br>2. Confirm<br>3. Post removed from feed |
| **Error Handling** | Permission denied / Restore on failure                     |

UC-7 Enable/Disable Feed Module (Admin only)
| Item              | Description                                                         |
| ----------------- | ------------------------------------------------------------------- |
| **Main Flow**     | Admin can toggle Feed Module availability in Admin Panel            |
| **Postcondition** | If disabled, Home Tab is hidden and replaced by maintenance message |
